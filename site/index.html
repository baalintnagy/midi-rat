THE MIDI RAT TERMINAL UTILITY BEHIND THE NETWORK

MIDI Rat is a terminal application for routing, inspecting, filtering, and transforming MIDI messages. Wire physical inputs and outputs through named buses and modules using YAML, then see what is happening in a live keyboard-driven workspace.

Download the latest release ↗ Browse source ↗ Explore a network ↓
YAML configuration & wiring Live terminal workspace Extensible with Java modules

Route & transform

Connect ports through broadcast buses. Filter messages and remap channels, notes, controllers, or values before forwarding them.

Inspect & understand

Follow traffic in colored monitors with timing, original device, immediate source, and note labels. Recognize chords from incoming notes.

Send & extend

Edit and send MIDI sequences with an emitter. Add external modules as JARs and inspect their status in focusable widgets and full-screen details.

Start in your terminal

The portable Windows release includes its Java runtime. Extract it, open a terminal in the MidiRat directory, and run these commands. The default emitter-and-monitor network needs no MIDI hardware.
